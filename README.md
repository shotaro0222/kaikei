# かいけい帳 — 個人事業主向け会計ソフト（Cloudflare 完結）

日々の記帳から確定申告書類の作成までを、**Cloudflare のサービスだけ**で動かす個人事業主向けの会計アプリです。

| 用途 | Cloudflare サービス |
| --- | --- |
| アプリ本体（API + 画面配信） | Workers ＋ Workers Static Assets（React SPA） |
| 帳簿データ | D1（SQLite） |
| 電子領収書・請求書の格納ドライブ / 日次バックアップ | R2 |
| 自動仕訳の AI 補助（任意） | Workers AI |
| 銀行明細の自動取得・バックアップ | Cron Triggers |
| メールで届いた領収書の自動保存（任意） | Email Routing ＋ Email Workers |
| ログイン保護（推奨） | Cloudflare Access（アプリ内パスワード認証も内蔵） |

## 主な機能

### 1. 確定申告に必要な書類の作成
- **青色申告決算書（一般用）** 4ページ分：損益計算書／月別売上・給料賃金・外注工賃・地代家賃の内訳／減価償却費の計算／貸借対照表
- **収支内訳書（白色申告）**
- **確定申告書 第一表（所得税）の概算**：所得控除（社会保険料・小規模企業共済・生命保険料・医療費・ふるさと納税など）、基礎控除（令和7年分以降の改正に対応、手入力で上書き可）、復興特別所得税、源泉徴収税額・予定納税額から納付／還付額を計算
- **消費税の集計**：免税／2割特例／簡易課税（第1〜6種）／本則課税
- 印刷・PDF 保存用レイアウト、国税庁「確定申告書等作成コーナー」への転記手順ガイド
- 決算整理：減価償却仕訳・家事按分振替・期末棚卸の自動作成（何度実行しても置き換え）、**翌年への繰越**（元入金の自動再計算と検算）

### 2. 利用用途を入力したら自動仕訳
- 「かんたん入力」で「Amazon でプリンターのインク」「電気代」のように入力すると勘定科目と税区分を推定し、支払方法（現金／事業用口座／カード／個人のお金）から仕訳を作成
- 推定の優先順位：**学習ルール**（確定した仕訳から自動学習）→ **登録ルール**（部分一致・完全一致・前方一致・正規表現）→ **組込み辞書**（約300語）→ **Workers AI**（判定できない場合のみ）
- 銀行・カード明細でも同じ仕組みで推定し、確度の高い明細は**一括仕訳**

### 3. 家事按分
- 費用科目ごとに事業割合（%）と根拠（床面積・使用時間など）を設定
- **決算時按分**：年間計上額から私用分を「事業主貸 / 経費」で振替（消費税の仕入税額も私用分を除外）
- **入力時按分**：入力のたびに「経費（事業分）＋ 事業主貸（私用分）/ 支払元」に分割。個人のお金で払った場合は事業分のみ記帳
- 減価償却資産は固定資産台帳の「事業専用割合」で按分

### 4. 電子領収書の格納ドライブと紐付け
- 画像・PDF を R2 にアップロード（ドラッグ＆ドロップ、かんたん入力からの添付）
- Google ドライブ・Dropbox・OneDrive などの**外部ドライブの共有リンクを登録**して紐付け
- 金額・日付が近い仕訳を候補表示して紐付け
- **電子帳簿保存法**を意識した設計：取引年月日・金額（範囲）・取引先で検索、SHA-256 ハッシュ保存、論理削除、訂正・削除履歴
- Email Workers で受信したメールの添付（PDF・画像）を自動で領収書として保存

### 5. 銀行口座との API 連携・CSV 取込
- **CSV 取込**：Shift_JIS / UTF-8 自動判定、ヘッダ名から列を自動判定（入金・出金が別列／1列の符号付き、カード明細の符号反転、和暦日付、△マイナス表記などに対応）。判定できない場合は画面で列を指定。重複取込を自動で防止
- **API 連携**：GMOあおぞらネット銀行 API（OAuth2 認可、または sunabar API 実験場のトークン直接登録）。トークンは AES-256-GCM で暗号化して保存し、Cron で毎日自動取得
- 口座・カード・電子マネー・現金出納帳を登録可能。プロバイダは `src/worker/lib/banks/` に追加して拡張可能

### その他の機能
- 仕訳帳（振替伝票・複数行仕訳、検索、CSV 出力）、総勘定元帳、残高試算表、月次推移
- 固定資産台帳：定額法（耐用年数省令の償却率）、一括償却資産（3年）、少額減価償却資産の特例、事業供用日・除却対応
- 期首残高の入力（元入金の自動計算）
- 勘定科目の追加（決算書の任意科目欄 ㉕〜㉚ に自動割当）
- ダッシュボード（売上・経費・所得・所得税見込み・月別グラフ・やることリスト）
- 全データの JSON バックアップ（手動 + R2 へ日次自動）

## セットアップ

### 前提
- Node.js 22 以上
- Cloudflare アカウント（`npx wrangler login` でログイン）

### ローカルで動かす

```bash
npm install
cp .dev.vars.example .dev.vars        # パスワード等を編集
npm run db:migrate:local              # ローカル D1 にテーブルを作成
npm run dev                           # http://localhost:5173
```

ローカルでは D1・R2 はローカル実行されます。Workers AI もローカル開発で使う場合は `CF_REMOTE_BINDINGS=1 npm run dev`（要 `wrangler login`）。AI が無くてもルール・辞書だけで自動仕訳は動作します。

### Cloudflare へデプロイ

```bash
# 1. D1 データベースと R2 バケットを作成
npx wrangler d1 create kaikei-db          # 省略可（初回デプロイ時に同名で自動作成されます）
npx wrangler r2 bucket create kaikei-receipts

# 2. テーブル作成
npm run db:migrate:remote

# 3. シークレットを設定
npx wrangler secret put APP_PASSWORD      # ログインパスワード
npx wrangler secret put SESSION_SECRET    # 32文字以上のランダム文字列
npx wrangler secret put ENCRYPTION_KEY    # 32文字以上のランダム文字列（銀行APIトークンの暗号化）

# 4. デプロイ
npm run deploy
```

ランダム文字列は `openssl rand -base64 32` などで生成してください。

### セキュリティ（推奨）
帳簿データを扱うため、アプリ内パスワードに加えて **Cloudflare Access（Zero Trust）** で Worker の URL を保護し、自分のメールアドレスだけがアクセスできるようにすることを推奨します。

### 銀行 API 連携（GMOあおぞらネット銀行）
- **本番**：GMOあおぞらネット銀行で API 利用申請を行い、リダイレクト URI に `https://<あなたのWorker>/api/bank/oauth/gmo/callback` を登録。`wrangler secret put GMO_AOZORA_CLIENT_ID` / `GMO_AOZORA_CLIENT_SECRET` を設定し、口座設定画面の「銀行で認可する」から接続します。法人口座の場合は `wrangler.jsonc` の `GMO_AOZORA_API_BASE` を法人用 URL に変更してください。
- **お試し（sunabar）**：口座設定で API URL に `https://api.sunabar.gmo-aozora.com/personal/v1` を入力し、sunabar ポータルで発行したアクセストークンを貼り付けます。

その他の銀行は、各行・アグリゲーション事業者との契約が必要なため CSV 取込をご利用ください。新しい API プロバイダは `BankProvider` インターフェース（`src/worker/lib/banks/types.ts`）を実装して `providerFor()` に追加すれば利用できます。

### メールで領収書を受け取る（任意）
Cloudflare ダッシュボードの Email Routing で、受付用アドレス（例：`receipts@example.com`）の転送先をこの Worker に設定します。添付の PDF・画像が R2 に保存され、「領収書・請求書」画面に未紐付けとして表示されます。

## 使い方の流れ

1. **事業者設定**：氏名・屋号・申告区分（青色/白色、控除額）・消費税の区分を登録し、期首残高を入力
2. **日々の記帳**：かんたん入力、または銀行・カード明細を取り込んで仕訳（推定結果を確認して「仕訳」／一括仕訳）
3. **領収書**：アップロードまたは外部ドライブのリンクを登録し、仕訳に紐付け
4. **家事按分・固定資産**：按分割合と資産を登録
5. **決算整理**（年末〜翌年初）：減価償却 → 家事按分 → 棚卸 → 申告書類の確認 → 翌年へ繰越
6. **確定申告書類**：決算書・申告書第一表・消費税を確認し、確定申告書等作成コーナーに転記して e-Tax で提出

## 開発

```bash
npm run typecheck   # 型チェック
npm test            # ユニットテスト（自動仕訳・家事按分・減価償却・所得税・消費税・CSV・決算書）
npm run build       # 本番ビルド

# API のシナリオテスト（空のローカル D1 に対して実行）
rm -rf .wrangler/state && npm run db:migrate:local && npm run build
npx vite preview --port 8787 &
npm run test:e2e
```

```

  lib/                 会計ロジック（純粋関数・テスト対象）

    dictionary.ts      組込みキーワード辞書
    journal.ts         仕訳の組み立て・検証・入力時按分
```

## 注意事項
- 金額はすべて税込経理・円単位の整数で扱います。
- 所得税・消費税の計算は概算です。税制改正（基礎控除の特例など）や各種控除の適用要件は、国税庁の確定申告書等作成コーナーまたは税理士に確認してください。
- e-Tax への直接送信（xtx 形式の出力）には対応していません。本アプリで作成した金額を確定申告書等作成コーナーに転記して提出してください。
- 帳簿・書類は 7 年間（一部 5 年）の保存義務があります。R2 のバケットを削除しないよう注意してください。
